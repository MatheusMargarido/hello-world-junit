# Hello World - JUnit (Projeto Maven)

Este é um projeto Java Maven que imprime "Hello, World!" e possui testes unitários com JUnit 5.

## Estrutura do Projeto

- `OlaMundo.java`: Classe principal que retorna uma mensagem.
- `OlaMundoTeste.java`: Classe de teste unitário.
- `pom.xml`: Arquivo de configuração Maven.

## Tecnologias

- Java 17
- Maven
- JUnit 5
- Eclipse
- Git & GitHub

## Como executar

1. Clone este repositório
2. Importe no Eclipse como um projeto Maven
3. Execute `OlaMundo.java`
4. Rode os testes com: `Run As > Maven Test`
